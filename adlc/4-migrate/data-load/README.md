# Data load agent

Owner: Data load agent · phase: migrate · deterministic

Generated by `src/generators/emit-adlc-index.js` from the agent specs. Do not edit; edit `src/agents/<agent>/agent.json`.

Moves the data into the target database in dependency order, keeping Salesforce record IDs, then recomputes roll-ups and records the Salesforce values used by verification. Also plans the history archive and the work in progress at go-live.

## Inputs

- `adlc/1-discover/extraction/data/*.csv`
- `adlc/3-build/*/sql/*.sql`
- target database connection (PGHOST, PGUSER, PGPASSWORD, PGDATABASE)
- `adlc/1-discover/extraction/inventory/retention.json`, fieldHistory.json, pendingApprovals.json, pausedFlows.json, scheduledJobs.json, asyncJobs.json

## Runs

- node src/generators/emit-cutover.js --parts work,history
- node src/app/scripts/load.js --recreate

## Outputs

- Target database: schema app with data
- migration.sf_expected (Salesforce values for verification)
- migration.run (load record)
- `adlc/4-migrate/data-load/work-in-progress.md`
- `adlc/4-migrate/data-load/history-archive.md`

## Done when

All rows loaded with 0 rejected, roll-ups recomputed, auto-number counters resynced

## Reviewer checks at the gate

- Row counts per object match the export
- Rejected rows
- Roll-up recompute count
- Each approval, paused flow and scheduled job is drained or carried over
- Retention per history source agreed with compliance
