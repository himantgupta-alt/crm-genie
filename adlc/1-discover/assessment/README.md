# Discovery agent

Owner: Discovery agent · phase: discover · deterministic

Generated by `src/generators/emit-adlc-index.js` from the agent specs. Do not edit; edit `src/agents/<agent>/agent.json`.

Reads what each regional org has built on top of standard Salesforce (read-only), matches every custom component to a business capability, and proposes a fit-gap verdict: adopt standard, replace with configuration, retain, harmonise, retire, or review with the business, and a fitment code per capability and org. Each org is assessed in its own context; cross-org patterns are insights, not a consolidation plan.

## Sub-agents

- **Org scan sub-agent**: Reads each org's configuration read-only: objects and fields with fill rates, rules, flows, code, packages, security, integrations, user interface and usage
- **As-is sub-agent**: Lists what each org has built on top of standard Salesforce and how much of it is used, reading the code function by function
- **Fit-gap sub-agent**: Matches every custom component to a business area and capability and proposes a verdict against the standard features
- **Report sub-agent**: Writes the Discovery Report and the data behind the Discovery explorer, including the business processes

## Inputs

- Salesforce orgs listed in src/agents/assessment/engagement.json (one CLI alias per org, read-only integration user)
- `src/agents/assessment/capabilities.json` (capability catalogue with the standard feature for each)

## Runs

- `src/generators/assess-org.js` (once per org; reads each Apex class and trigger function by function with src/generators/apex-functions.js)
- `src/generators/discover-org.js` (once per org)
- `src/generators/emit-assessment.js`
- `src/generators/emit-discovery.js`

## Outputs

- `adlc/1-discover/assessment/discovery-report.md` (one Discovery Report for all orgs: executive summary, findings with risk and priority, landscape, data model, fit-gap, roadmap, appendix per org)
- `adlc/1-discover/assessment/discovery/` (complete discovery per org as data, behind the report and the Discovery explorer)
- `adlc/1-discover/assessment/orgs/` (as-is per org: components, counts, fill rates, markets; no record contents)
- `adlc/1-discover/assessment/fit-gap.json` (every component with capability and verdict, cross-org matrix, and the function-level fit-gap of the Apex code: business functions with verdict and confidence, effort, regression and value, quick wins, cross-cutting findings, order of execution)
- `adlc/1-discover/assessment/assessment-report.md` (summary, as-is, comparison, fit-gap, workshop list)
- `adlc/1-discover/assessment/architecture.md` (principles, how the assessment runs, verdict flow, target direction)

## Done when

Every connected org extracted, every custom component classified with a verdict and a reason, report and architecture written

## Reviewer checks at the gate

- Every org in the engagement is extracted, or its absence is explained
- Markets found match the market list agreed for the engagement
- Adopt-standard verdicts name a licensed feature, or the licence is on the workshop agenda
- Retire candidates are confirmed unused with the business owner
- Review items are on the workshop agenda
