# Vendor packages

Generated by `scripts/emit-cutover.js` from `output/inventory/`. Owner: **Modelling agent**, reviewed at that agent's gate.

Managed-package code is compiled and hidden by Salesforce. What we can take: the package's objects and fields (in the blueprint), its data and its configuration records (in the data export). Behaviour is captured as input → output test cases, then each package is rebuilt, replaced or kept on Salesforce by agreement.
