# Business Rules & Automations

## Validation Rules (record rejected when condition is true)

- **Opportunity.Closed_Won_Requires_Amount**: `AND( ISPICKVAL(StageName, "Closed Won"), OR( ISBLANK(Amount), Amount <= 0 ) )` → "A won opportunity must have an Amount greater than zero."
- **Opportunity.Loss_Reason_Required_When_Lost**: `AND( ISPICKVAL(StageName, "Closed Lost"), ISBLANK(TEXT(Loss_Reason__c)) )` → "A Loss Reason is required before an opportunity can be marked Closed Lost."
- **Subscription_Line__c.Parent_Not_Cancelled**: `ISPICKVAL(Subscription__r.Status__c, "Cancelled")` → "You cannot add or change lines on a cancelled subscription."
- **Subscription_Line__c.Quantity_Must_Be_Positive**: `Quantity__c <= 0` → "Quantity must be greater than zero."
- **Subscription__c.Active_Requires_MRR**: `AND( ISPICKVAL(Status__c, "Active"), OR( ISBLANK(MRR__c), MRR__c <= 0 ) )` → "An active subscription must have an MRR greater than zero."
- **Subscription__c.Cancellation_Reason_Required**: `AND( ISPICKVAL(Status__c, "Cancelled"), ISBLANK(Cancellation_Reason__c) )` → "Cancellation Reason is required when Status is Cancelled."
- **Subscription__c.End_Date_After_Start_Date**: `AND( NOT(ISBLANK(Start_Date__c)), NOT(ISBLANK(End_Date__c)), End_Date__c <= Start_Date__c )` → "End Date must be after Start Date."
- **Subscription__c.No_Reactivation_After_Cancel**: `AND( ISCHANGED(Status__c), ISPICKVAL(PRIORVALUE(Status__c), "Cancelled"), NOT(ISPICKVAL(Status__c, "Cancelled")) )` → "A cancelled subscription cannot be reactivated. Create a new subscription instead."

## Formula & Roll-up Fields

- Subscription_Line__c.Account_Name__c: `Subscription__r.Account__r.Name`
- Subscription_Line__c.Line_Total__c: `Quantity__c * Unit_Price__c`

- Subscription__c.Days_To_Renewal__c: `End_Date__c - TODAY()`

- Subscription__c.Total_Line_Value__c: sum(Subscription_Line__c.Line_Total__c) from Subscription_Line__c.Subscription__c
